
# 🌌 SilentRP — Modular MTA:SA Roleplay Server Framework

[![MTA:SA Version](https://img.shields.io/badge/MTA%3ASA-1.6%2B-blue.svg)](https://multitheftauto.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Architecture: Event--Driven](https://img.shields.io/badge/Architecture-Event--Driven%20%7C%20MVC-orange.svg)](#معماری-فنی-و-الگوهای-طراحی)

پروژه **SilentRP** یک چارچوب (Framework) ماژولار و مبتنی بر معماری رویداد‌محور (Event-Driven) برای سرورهای **Multi Theft Auto: San Andreas (MTA:SA)** است. این پروژه با هدف پیاده‌سازی سیستم‌های بازی نقش‌آفرینی (Roleplay) در مقیاس صنعتی، تفکیک وظایف (Separation of Concerns)، بهینه‌سازی بار پردازشی سرور و استفاده بهینه از چرخه شبکه (Network Bandwidth) طراحی و توسعه یافته است.

## 🏛 معماری فنی و الگوهای طراحی

در طراحی چارچوب SilentRP، اصول مهندسی نرم‌افزار زیر مدنظر قرار گرفته‌اند:
1. **Client-Server RPC (Remote Procedure Calls):** بهره‌گیری از رویدادهای سفارشی (`triggerServerEvent` و `triggerClientEvent`) همراه با اعتبارسنجی ورودی‌ها در لایه سرور جهت جلوگیری از حملات Memory Injection و فرستادن پکت‌های نامعتبر.
2. **کپسوله‌سازی ماژولار (Modular Encapsulation):** هر سیستم به صورت یک بسته مستقل (Resource) توسعه یافته و ارتباط بین آن‌ها از طریق توابع Export شده صورت می‌پذیرد.
3. **لایه رابط کاربری مدرن (CEF Integration):** تفکیک لایه منطق بازی (Lua) از لایه بصری (HTML/CSS/JS) با استفاده از Chromium Embedded Framework جهت پیاده‌سازی رابط کاربری پویا و سبک.

🚀 راهنمای راه‌اندازی محیط توسعه (Setup)

1.  کلون کردن ریپازیتوری:
    git clone https://github.com/Silent-Galaxy/SilentRP.git
2.  قرار دادن در سرور:
    پوشه پروژه را در مسیر server/mods/deathmatch/ قرار دهید.
3.  پیکربندی پایگاه داده:
    تنظیمات کانکشن دیتابیس را در فایل‌های پیکربندی ریسورس‌های پایه‌ای (مانند
    auth) مشخص کنید.
4.  اجرای سرور:
    فایل اجرایی mta-server.exe را اجرا کنید.
